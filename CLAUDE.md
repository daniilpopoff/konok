# Konok — контекст для Claude

Дипломный проект (ВКР): CRM для посуточной аренды квартир в Бишкеке. Даниил Попов — бэкенд, Белек Корчуев — фронтенд.
30% работы показываем руководителю к 7 декабря 2026. Общайся по-русски, просто и по-человечески.

## Продукт
- SaaS: каждый рантье регистрируется, получает витрину `/{логин}` и ссылки на квартиры для Lalafo/Instagram (`?src=`).
- Роли: владелец, менеджер (без финансов и настроек), гость без регистрации, админ платформы.
- Оплата: фиксированная предоплата переводом + чек → ручное подтверждение (CRM или кнопка в Telegram).
  Остаток и залог — при передаче ключей, в системе только отметки. Оплата на счёт ИП — потом.
- Даты держатся 30 минут до загрузки чека. Только посуточно (модель хранит дату+время ради почасовой в будущем).
- Нет: общего каталога, «умной» части, мобильного приложения (потом), iCal, мультиязычности (потом).
- Полное ТЗ и PRD — в Claude Docs; архитектура и API — `docs/architecture.md`.

## Код
- `backend/` — Python 3.13, FastAPI, SQLAlchemy 2.0, PostgreSQL 16 (+btree_gist), pytest.
- `backend/app/services/booking.py` — вся логика броней. Статусы меняются ТОЛЬКО через `transition()`.
- Двойную бронь не допускает EXCLUDE-ограничение `bookings_no_overlap` в базе — не заменять проверкой в коде.
- Все данные фильтруются по `account_id`; чужое отвечает 404.
- Деньги — Decimal/Numeric(12,2), время — timestamptz, часовой пояс Asia/Bishkek.
- Чеки — в `media/private`, отдаются только через API с проверкой прав.

## Команды
- Запуск: `docker compose up --build` → http://localhost:8000/docs
- Демо-данные: `docker compose exec backend python seed.py` (azamat@konok.kg / password123)
- Тесты (один раз создать базу: `docker compose exec db createdb -U konok konok_test`):
  `docker compose exec backend pytest -q` — идут в konok_test (TEST_DATABASE_URL), перед каждым коммитом зелёные.
